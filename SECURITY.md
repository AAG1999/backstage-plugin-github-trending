# Security

Report vulnerabilities privately. Do not open a public GitHub issue for a security report.

- GitHub: [Security advisories](https://github.com/AAG1999/backstage-plugin-github-trending/security/advisories/new)
- Maintainer: [@AAG1999](https://github.com/AAG1999)

Please include the affected package (`@aag1999/plugin-github-trending`, `-backend`, or `-common`), a description of the issue, and steps to reproduce.
